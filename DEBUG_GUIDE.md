# Руководство по отладке системы управления руками

## 🔍 Диагностика проблем

### Проблема: Кнопка X не работает

**Шаги диагностики:**

1. **Проверьте логи при запуске:**
```bash
rosrun teleop_fetch fetcher.py
```
Должны появиться сообщения:
```
[INFO] Начальное состояние управления руками: idle
[INFO] Для калибровки нажмите X на левом контроллере
```

2. **Проверьте данные VR контроллеров:**
```bash
rostopic echo /quest/joints
```
Должны видеть данные с кнопками L_X, L_Y, R_A, R_B

3. **Запустите тест кнопок:**
```bash
rosrun teleop_fetch test_button_logic.py
```
Этот скрипт покажет, обрабатываются ли нажатия кнопок.

### Ожидаемые сообщения при нажатии X:

```
[INFO] Кнопка X нажата! Текущее состояние: idle
[INFO] Запуск калибровки...
[INFO] === НАЧАЛО КАЛИБРОВКИ РУК ===
[INFO] === КАЛИБРОВКА РУК ===
```

### Проблема: Калибровка не завершается

**Проверьте:**
1. Есть ли данные о руках в топике `/quest/poses`
2. Передаются ли данные о левой и правой руке

**Команда для проверки:**
```bash
rostopic echo /quest/poses
```

### Проблема: Робот не двигается после калибровки

**Проверьте:**
1. Подключение к топику управления руками:
```bash
rostopic echo /ros_robot_controller/bus_servo/set_position
```

2. Логи должны показывать:
```
[INFO] === КАЛИБРОВКА ЗАВЕРШЕНА ===
[INFO] Управление руками активировано
```

## 🛠️ Команды для диагностики

### Проверка топиков:
```bash
# Список всех топиков
rostopic list

# Проверка данных VR
rostopic echo /quest/joints
rostopic echo /quest/poses

# Проверка команд управления
rostopic echo /ros_robot_controller/bus_servo/set_position
```

### Проверка нод:
```bash
# Список активных нод
rosnode list

# Информация о ноде
rosnode info /teleop_fetch
```

## 📋 Чек-лист для отладки

- [ ] VR гарнитура подключена и работает
- [ ] Данные поступают в `/quest/joints` (кнопки)
- [ ] Данные поступают в `/quest/poses` (руки)
- [ ] Нода `teleop_fetch` запущена
- [ ] В логах видно "Кнопка X нажата!"
- [ ] Состояние меняется с `idle` на `calibrating`
- [ ] Данные о руках сохраняются при калибровке
- [ ] Состояние меняется на `controlling`
- [ ] Команды отправляются в `/ros_robot_controller/bus_servo/set_position`

## 🚨 Частые проблемы

### 1. "Нет данных о руках для калибровки"
**Решение:** Проверьте подключение VR гарнитуры и топик `/quest/poses`

### 2. "Кнопка X нажата!" не появляется
**Решение:** Проверьте топик `/quest/joints` и значения L_X

### 3. Робот не реагирует на движения
**Решение:** Проверьте топик `/ros_robot_controller/bus_servo/set_position`

### 4. Состояние не меняется
**Решение:** Перезапустите ноду и проверьте логи
