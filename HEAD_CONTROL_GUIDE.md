# Руководство по управлению головой

## 🎯 Новая функциональность

Управление головой робота теперь синхронизировано с управлением руками и контролируется теми же кнопками.

## 🔄 Логика работы

### Состояния системы:

1. **idle** - Управление отключено
   - Голова: ❌ Отключено
   - Руки: ❌ Отключено

2. **calibrating** - Калибровка
   - Голова: ❌ Отключено
   - Руки: 🔄 Калибровка

3. **controlling** - Активное управление
   - Голова: ✅ Включено
   - Руки: ✅ Включено

## 🎮 Управление кнопками

### Кнопка X (левая):
- **idle → calibrating**: Начало калибровки
- **calibrating → controlling**: Завершение калибровки и активация управления

### Кнопка Y (левая):
- **controlling → idle**: Остановка управления и возврат в стартовую позу

## 📊 Ожидаемые логи

### При запуске:
```
[INFO] Начальное состояние управления руками: idle
[INFO] Управление головой: отключено
```

### При калибровке (первое нажатие X):
```
[INFO] === КАЛИБРОВКА РУК ===
[INFO] Управление головой: отключено
```

### При активации управления (второе нажатие X):
```
[INFO] === КАЛИБРОВКА ЗАВЕРШЕНА ===
[INFO] Управление руками и головой активировано
```

### При остановке (нажатие Y):
```
[INFO] === ОСТАНОВКА УПРАВЛЕНИЯ РУКАМИ И ГОЛОВОЙ ===
```

## ✅ Преимущества

1. **Синхронизация**: Голова и руки управляются вместе
2. **Безопасность**: Голова не двигается случайно
3. **Простота**: Одна система управления для всего робота
4. **Контроль**: Оператор полностью контролирует, когда робот активен

## 🔧 Технические детали

- Управление головой блокируется флагом `head_control_enabled`
- Флаг автоматически управляется состояниями `arm_control_state`
- При калибровке голова остается неподвижной
- При активном управлении голова следует движениям оператора
