# Руководство по управлению руками робота

## 🎮 Управление через VR контроллеры

### Основные кнопки:
- **X (левая кнопка)** - Калибровка/начало управления
- **Y (левая кнопка)** - Остановка управления
- **Grip (хватка)** - Управление захватами рук

## 📋 Пошаговая инструкция

### 1. Запуск системы
```bash
rosrun teleop_fetch fetcher.py
```

### 2. Калибровка рук
1. Наденьте VR гарнитуру
2. Нажмите **X** на левом контроллере
3. Выставьте руки в стартовую позу (как у робота)
4. Снова нажмите **X** для завершения калибровки

### 3. Управление руками
- Двигайте руками - робот повторяет движения в масштабе 1:5
- Сжимайте контроллеры для управления захватами
- Робот автоматически масштабирует движения

### 4. Остановка управления
- Нажмите **Y** на левом контроллере
- Робот вернется в стартовую позу
- Для продолжения повторите калибровку

## 🔧 Технические детали

### Масштабирование
- Робот в 5 раз меньше оператора
- Коэффициент масштабирования: 0.2
- Движения автоматически адаптируются

### Обратная кинематика
- **X-смещение** → поворот плеча вперед-назад
- **Y-смещение** → подъем плеча вверх-вниз  
- **Z-смещение** → поворот предплечья

## ⚠️ Важные замечания

1. **Калибровка обязательна** - без неё управление не работает
2. **Стартовая поза** - руки должны соответствовать начальной позе робота
3. **Масштабирование** - движения робота в 5 раз меньше движений оператора
4. **Безопасность** - всегда проверяйте рабочее пространство робота

## 🐛 Устранение неполадок

### Проблема: Калибровка не работает
- Убедитесь, что VR гарнитура подключена
- Проверьте, что данные поступают в топик `/quest/poses`
- Попробуйте перезапустить ноду

### Проблема: Робот не двигается
- Проверьте подключение к топику `/ros_robot_controller/bus_servo/set_position`
- Убедитесь, что калибровка завершена успешно
- Проверьте логи на наличие ошибок

### Проблема: Неточные движения
- Перекалибруйте систему
- Проверьте масштабирование
- Убедитесь, что руки в правильной стартовой позе
