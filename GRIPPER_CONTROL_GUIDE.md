# Руководство по управлению захватами

## 🎯 Новая функциональность

Управление захватами теперь работает с кнопками **index** и **grip**, с запоминанием последнего положения, центральным положением 500 и инверсией левого захвата.

## 🎮 Управление кнопками

### Левый захват:
- **index** (указательный палец) → Сжимает захват
- **grip** (хватка) → Разжимает захват

### Правый захват:
- **index** (указательный палец) → Сжимает захват  
- **grip** (хватка) → Разжимает захват

## 🔄 Логика работы

### Состояния захватов:
- **0.0** = Полностью закрыт (правый: 300, левый: 700)
- **0.5** = Центральное положение (500)
- **1.0** = Полностью открыт (правый: 700, левый: 300)
- **Промежуточные значения** = Частично открыт/закрыт

### Запоминание положения:
- Если отпустить кнопки, захват остается в последнем положении
- Изменение происходит постепенно (шаг 0.1 за нажатие)
- Состояние сохраняется до следующего нажатия

## 🛡️ Ограничения безопасности

### Диапазон движения:
- **Центральное положение**: 500
- **Пределы**: ±200 от центра (300-700)
- **Безопасность**: Предотвращает повреждение захватов

### Ограничения углов:
```python
left_gripper_pos = max(300, min(700, left_gripper_pos))
right_gripper_pos = max(300, min(700, right_gripper_pos))
```

## 🔧 Технические детали

### Переменные состояния:
```python
self.left_gripper_state = 0.5   # Состояние левого захвата (центральное)
self.right_gripper_state = 0.5   # Состояние правого захвата (центральное)
```

### Логика управления:
```python
# Сжимание (index)
if left_index > 0.5:
    self.left_gripper_state = max(0.0, self.left_gripper_state - 0.1)

# Разжимание (grip)  
elif left_grip > 0.5:
    self.left_gripper_state = min(1.0, self.left_gripper_state + 0.1)
```

### Преобразование в углы:
```python
# Центральное положение = 500, пределы ±200
# Левый захват инвертирован: 0.0 = открыт (700), 1.0 = закрыт (300)
# Правый захват: 0.0 = закрыт (300), 1.0 = открыт (700)
left_gripper_pos = int(500 + (1.0 - self.left_gripper_state) * 200)  # Инвертировано
right_gripper_pos = int(500 + self.right_gripper_state * 200)  # Обычно
```

## 🚀 Автоматический сброс

### При остановке управления (кнопка Y):
- Захваты автоматически возвращаются в центральное положение (500)
- Состояния сбрасываются в 0.5
- Робот возвращается в безопасное положение

### При калибровке:
- Захваты остаются в текущем положении
- Управление захватами отключено

## ✅ Преимущества

1. **Интуитивность**: index = сжимать, grip = разжимать
2. **Безопасность**: Ограниченный диапазон движения
3. **Контроль**: Запоминание последнего положения
4. **Плавность**: Постепенное изменение состояния
5. **Автоматика**: Сброс при остановке управления
