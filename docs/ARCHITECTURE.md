## 3. Потоки данных

### VR → Робот (руки)

| Этап | Топик/Узел | Данные |
|------|------------|--------|
| 1 | `/quest/poses` | PoseArray: head, left_hand, right_hand (сырые Quest) |
| 2 | vr_remapper | map → offset → scale |
| 3 | `/teleop_fetch/quest_poses_remapped` | body_link, готовые для IK |
| 4 | pose_source | merge VR / manual |
| 5 | `/teleop_fetch/poses` | PoseArray в body_link |
| 6 | fast_ik_node | IK → joint values → servo positions |
| 7 | `/teleop_fetch/arm_servo_targets` | SetBusServosPosition |
| 8 | teleop_fetch | → bus_servo (при X=enable) |

### Калибровка (R_A)

| Событие | Действие |
|---------|----------|
| R_A нажат | vr_remapper: offset = reference_pose - mapped_vr |
| Дальше | output = mapped_vr + offset; output *= scale |

### Scale (чувствительность)

| Источник | Топик | Диапазон |
|----------|-------|----------|
| UI (teleop_debug.html) | `/teleop_fetch/scale` | 0.0001 .. 100 |
| Обновление | на лету при изменении поля |

## 4. Решённые проблемы (beta 1.0)

- **Y/Z инверсия:** Маппинг Quest→body_link вынесен в одно место (`_controller_to_body_link`), убраны дубли и post_mapping.
- **Калибровка без T-позы:** Эталонная поза робота (руки перед собой) + R_A. Оператор приводит руки в похожее положение — offset вычисляется автоматически.
- **Смещения и scale в одном блоке:** Всё в vr_remapper; fast_ik получает готовые координаты.
- **Чувствительность:** Один параметр SCALE (0.0001..100), обновляется из UI на лету.

## 5. Конфигурация

| Файл | Назначение |
|------|------------|
| `teleop_fetch/config/vr_remapper.yaml` | reference_pose, scale по умолчанию |
| `teleop_fetch/config/teleop.yaml` | servo IDs, arm start, head, VR topics |
| `my_package/config/fast_ik.yaml` | gripper, move_groups, left_hand conversion |
